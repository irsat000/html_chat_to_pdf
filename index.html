Chat archive → PDF

Drop in one or more saved chat pages (the standalone .html exports) to turn them into readable PDFs, asterisk-emphasis and emoji all included. Everything happens in this tab — nothing is uploaded anywhere. Files are converted one at a time to keep the tab responsive on large chats.

Drop saved chat files here, or browse
Accepts multiple .html exports at once (processed one by one)
How it reads your file: it looks for the chat data embedded in the saved page (the same JSON your chat-export extension writes into it), then lays out each message as a white message bubble — *single* asterisks become italic, **double** become bold, and ***triple*** become bold-italic, matching how the saved page itself displays them. Emoji are rendered as small images rather than text, since PDF's built-in fonts can't draw them reliably.
